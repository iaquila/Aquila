6. 404s return HTML, not the JSON envelope
====================================================================
GET /nonexistent-endpoint
HTTP 404, content-type: text/html
<!DOCTYPE html> ... <h1>404</h1> ... Proudly powered by LiteSpeed Web Server

Problem: any unknown path falls through to the web server instead of your API, so the
client gets a 9900-character HTML page.ihadto specialcase this to
avoid trying to JSON-parse it.
Fix: route 404s through the API so they return
{"statusCode":404,"success":false,"messages":["Not found"],"data":null}.

7. Validation failures return 500 instead of 400/404
====================================================================
POST /candidate/create {"election":2,"party":7,"position":1,"name":"x"}
HTTP 500  {"messages":["Election not found."]}

POST /candidate/create {}
HTTP 400  {"messages":["Election is missing","Party is missing","Position is missing",
                       "Name is missing"]}

Problem: a missing record is a 404 (or at worst 400), not a 500. Only the
presence checks use 400. Same pattern elsewhere — a bad electoral-area hierarchy
returns 500 with "A 'country' area cannot be the parent of a 'ward' area".
so400 for bad input, 404 for missing records, 500 reserved for real faults.
A 500 also makes the client retry logic think the server is broken.


====================================================================
8. Invalid enum values return 401 Unauthorized instead of 400
====================================================================
PATCH /incident/edit/66 {"status":"RESOLVED"}
HTTP 401  {"messages":["Invalid incident status."]}

PATCH /incident/edit/66 {"severity":"critical"}
HTTP 401  {"messages":["Invalid incident severity."]}

Problem: 401 means "not authenticated" and makes clients attempt a token refresh
before retrying a request that can never succeed. Should be 400/422.
Also please document the allowed values. enforced:
  status:   open | close          (not UNDER_REVIEW, not RESOLVED, not uppercase)
  severity: low | medium | high   (no critical)
